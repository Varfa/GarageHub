# GarageHub

Backend application for automotive service management built with Go and PostgreSQL.

---

## About

GarageHub is a backend application designed to manage the daily operations of an automotive repair workshop.

The project is inspired by real service center workflows and focuses on building a clean, scalable backend architecture using Go and PostgreSQL.

Current development includes customer management, vehicle management, repair orders, mechanics, repair tasks, authentication, role-based access control, and reporting.

---

## Features

- Authentication
- Role-Based Access Control (RBAC)
- Customer Management
- Vehicle Management
- Repair Orders
- Repair Tasks
- Mechanics Management
- Reports
- REST API
