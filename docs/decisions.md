
# GarageHub

## Архитектурные решения

### Общие правила

- Код пишется на английском языке.
- URL всегда на английском языке.
- CSS-классы всегда на английском языке.
- Все пользовательские тексты поддерживают мультиязычность.
- Для переводов используется атрибут `data-i18n`.

---

### Интерфейс

- Используется единый шаблон `layout.html`.
- Меню навигации всегда остается статичным.
- Меняется только рабочая область (`content`).
- Используются семантические HTML5-теги (`header`, `main`, `nav`, `section`).

---

### Переводы

Ключи переводов всегда на английском языке.

Пример:

```html
data-i18n="nav.clients"
data-i18n="button.logout"
```

Структура ключей:

- `nav.*` — меню.
- `button.*` — кнопки.
- `title.*` — заголовки.
- `label.*` — подписи полей.
- `table.*` — заголовки таблиц.
- `message.*` — сообщения пользователю.
- `error.*` — ошибки.

---

### Язык интерфейса

Поддерживаемые языки:

- Russian (`ru`)
- English (`en`)
- Lithuanian (`lt`)

До авторизации:

- язык по умолчанию — `ru`;
- пользователь может изменить язык;
- выбор сохраняется в `localStorage`.

После авторизации:

- язык загружается из базы данных (`preferred_language`);
- пользователь может изменить язык;
- новый язык сохраняется в базе данных.

---

### Пользователь

В будущем таблица пользователей будет содержать поле:

preferred_language

---

### Dashboard

Главная страница должна отображать ключевую информацию о работе автосервиса.

Основная цель Dashboard — за 10 секунд дать пользователю понять текущее состояние бизнеса.

На Dashboard будут размещаться информационные карточки и важные показатели системы.
---

Перед реализацией новой функции сначала принимается архитектурное решение.

После этого:

2. Реализуется Backend.
3. Реализуется Frontend.
4. При необходимости добавляется документация.
